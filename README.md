# 📝 Notes App

A modern Notes App built with **HTML**, **Tailwind CSS**, and **Vanilla JavaScript**.

This project allows users to create, save, and delete notes dynamically while persisting data using the browser's Local Storage API.

## 🔥 How It Works

1. User enters a title and note.
2. JavaScript creates a note object.
3. The object is pushed into an array.
4. The array is stored in Local Storage.
5. Notes are rendered dynamically as cards.
6. On page reload, notes are restored from Local Storage.
